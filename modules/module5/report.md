# Module 5 - Option 2: Bookstore Points

## Pseudocode

1. Define constants to determine the different reward tiers and the number of books needed to award them
  - 0 books: 0 points
  - 2 books: 5 points
  - 4 books: 15 points
  - 6 books: 30 points
2. Prompt user for the number of books they purchased this month
3. Validate the input (non-negative). If invalid, print an error and exit
4. Use conditional statements to determine the amount of points the user has earned
5. Display the points to the user
